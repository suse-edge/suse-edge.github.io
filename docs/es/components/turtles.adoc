[quote]
____
Rancher Turtles es un operador de Kubernetes que proporciona integración entre Rancher Manager y Cluster API (CAPI) con el objetivo de brindar soporte de CAPI completo a Rancher
____


== Características clave de Rancher Turtles

* Importación automática de clústeres CAPI en Rancher mediante la instalación del agente de clúster de Rancher en clústeres aprovisionados por CAPI.
* Instale y configure las dependencias del controlador CAPI a través del https://cluster-api-operator.sigs.k8s.io/[Operador CAPI].

== Uso de Rancher Turtles en SUSE Edge

La pila SUSE Edge proporciona un wrapper chart de Helm que instala Rancher Turtles con una configuración específica que permite:

* Componentes del controlador kernel de CAPI
* Componentes del plano de control y del proveedor de iniciar de RKE2
* Componentes del proveedor de infraestructura <<components-metal3,Metal3>>

Solo se admiten los proveedores predeterminados instalados a través del wrapper chart; los proveedores alternativos del plano de control, de iniciar y de infraestructura no se admiten actualmente como parte de la pila SUSE Edge.

== Instalación de Rancher Turtles

Rancher Turtles puede instalarse siguiendo la guía <<quickstart-metal3,Metal3 Quickstart>> o la documentación de <<atip-management-cluster,Management Cluster>>.
