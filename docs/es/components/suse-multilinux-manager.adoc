= SUSE Multi-Linux Manager
:revdate: 2025-01-28
:revnumber: 3.6
:page-revdate: {revdate}
:experimental:


SUSE Multi-Linux Manager se incluye en {product} para proporcionar automatización y control con el fin de mantener SUSE Linux Micro como el sistema operativo subyacente constantemente actualizado en todos los nodos de vuestra ampliación edge.

Para obtener más información, consultad <<quickstart-suma>> y la https://documentation.suse.com/suma/5.0/en/suse-manager/index.html[SUSE Multi-Linux Manager Documentation].
