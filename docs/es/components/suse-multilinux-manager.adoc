= SUSE Multi-Linux Manager
:revdate: 2025-01-28
:revnumber: 3.4
:page-revdate: {revdate}
:experimental:


SUSE Multi-Linux Manager se incluye en SUSE Edge para proporcionar automatización y control que garanticen que SUSE Linux Micro, como sistema operativo subyacente, se mantenga constantemente actualizado en todos los nodos de su ampliación edge.

Para obtener más información, consultad <<quickstart-suma>> y la https://documentation.suse.com/suma/5.0/en/suse-manager/index.html[SUSE Multi-Linux Manager Documentation].
