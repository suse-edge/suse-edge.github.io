Las extensiones permiten a los usuarios, desarrolladores, socios y clientes ampliar y mejorar la interfaz de usuario de Rancher. {product} proporciona extensiones del Dashboard de KubeVirt.

Consulte `{link-rancher-extensions}[Rancher documentation]` para obtener información general sobre las extensiones de Rancher Dashboard.

== Instalación

Todos los componentes de {product} {version-edge} , incluidas las extensiones del Dashboard, se distribuyen como artefactos OCI. Para instalar las extensiones {product}, puede utilizar la interfaz de usuario de Rancher Dashboard, Helm o Fleet:

=== Instalación con Rancher Dashboard UI

. Haga clic en *Extensiones* en la sección *Configuración* de la barra lateral de navegación.
. En la página de Extensiones, haga clic en el menú de tres puntos en la parte superior derecha y seleccione *Gestionar repositorios*.
+
Cada extensión se distribuye a través de su propio artefacto OCI. Están disponibles en el repositorio de charts de Helm de {product}. 

. En la página de *repositorios*, haga clic en `Create`.
. En el formulario, especifique el nombre y la URL del repositorio y haga clic en `Create`.
+
{product} URL del repositorio de Helm charts de:
`oci://registry.suse.com/edge/charts`
+
image::dashboard-extensions-create-oci-repository.png[scaledwidth=100%]

. Puede ver que el repositorio de extensiones se ha añadido a la lista y se encuentra en estado `Active`.
+
image::dashboard-extensions-repositories-list.png[scaledwidth=100%]

. Vuelva a *Extensiones* en la sección *Configuración* de la barra lateral de navegación.
+
En la pestaña *Disponibles* puede ver las extensiones disponibles para su instalación.
+
image::dashboard-extensions-available-extensions.png[scaledwidth=100%]

. En la tarjeta de la extensión, haga clic en `Install` y confirme la instalación.
+
Una vez instalada la extensión, la interfaz de usuario de Rancher solicita recargar la página como se describe en `https://ranchermanager.docs.rancher.com/{rancher-docs-version}/integrations-in-rancher/rancher-extensions#installing-extensions[]`.


=== Instalación con Helm

[,bash,subs="attributes"]
----
# KubeVirt extension
helm install kubevirt-dashboard-extension oci://registry.suse.com/edge/charts/kubevirt-dashboard-extension --version {version-kubevirt-dashboard-extension-chart} --namespace cattle-ui-plugin-system
----

[NOTE]
====
Las extensiones deben instalarse en el espacio de nombres `cattle-ui-plugin-system`.
====

[NOTE]
====
Después de instalar una extensión, es necesario recargar la interfaz de usuario de Rancher Dashboard. 
====

=== Instalación con Fleet

La instalación de extensiones de Dashboard con Fleet requiere definir un recurso `gitRepo` que apunte a un repositorio Git con archivo(s) de configuración de paquete `fleet.yaml` personalizado(s).

[,yaml,subs="attributes"]
----
# KubeVirt extension fleet.yaml
defaultNamespace: cattle-ui-plugin-system
helm:
  releaseName: kubevirt-dashboard-extension
  chart: oci://registry.suse.com/edge/charts/kubevirt-dashboard-extension
  version: "{version-kubevirt-dashboard-extension-chart}"
----

[NOTE]
====
La propiedad `releaseName` es obligatoria y debe coincidir con el nombre de la extensión para que esta se instale correctamente.
====

[,yaml]
----
cat <<- EOF | kubectl apply -f -
apiVersion: fleet.cattle.io/v1alpha1
metadata:
  name: edge-dashboard-extensions
  namespace: fleet-local
spec:
  repo: https://github.com/suse-edge/fleet-examples.git
  branch: main
  paths:
  - fleets/kubevirt-dashboard-extension/
EOF
----

Para obtener más información, consulte <<components-fleet>> y el repositorio `https://github.com/suse-edge/fleet-examples[fleet-examples]`.

Una vez instaladas las extensiones, aparecen en la sección *Extensiones* bajo la pestaña *Instaladas*. Dado que no se instalan a través de Aplicaciones/Marketplace, están marcadas con la etiqueta `Third-Party`.

image::installed-dashboard-extensions.png[scaledwidth=100%]

== Extensión de Dashboard de KubeVirt

La extensión de KubeVirt proporciona una gestión básica de máquinas virtuales para la interfaz de usuario de Rancher Dashboard. Sus capacidades se describen en <<kubevirt-dashboard-extension-usage>>.
