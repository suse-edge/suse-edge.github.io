[quote]
____
Rancher Turtles 是一个 Kubernetes 操作器，可实现 Rancher Manager 与 Cluster API (CAPI) 之间的集成，旨在为 Rancher 提供完整的 CAPI 支持
____


== Rancher Turtles 的主要功能

* 通过在 CAPI 配置的集群中安装 Rancher Cluster Agent，自动将 CAPI 集群导入 Rancher。
* 通过 https://cluster-api-operator.sigs.k8s.io/[CAPI Operator] 安装并配置 CAPI 控制器依赖项。
* 通过 `CAPIProvider` API 管理已安装的 CAPI 提供程序依赖项

== Rancher Turtles 在 {product} 中的使用

{product} 堆栈提供了一个 `rancher-turtles-providers` Helm chart，可通过 `CAPIProvider` API 启用特定的 CAPI 提供程序：

* RKE2 控制平面和启动提供程序
* <<components-metal3,Metal3>> 基础架构提供程序
* <<components-metal3,Metal3>> IPAM 提供程序（目前不支持）
* Fleet 插件提供程序

仅支持通过封装程序 chart 安装的默认提供程序 - 目前不支持将替代的控制平面、启动提供程序和基础架构提供程序作为 {product} 堆栈的一部分。

== 安装 Rancher Turtles

自 Rancher 2.13 起，安装 Rancher 时默认启用 Rancher Turtles。

Rancher Turtles 提供程序可以按照 <<quickstart-metal3,Metal3 快速入门>> 指南或 <<atip-management-cluster,管理集群>> 文档进行安装。
