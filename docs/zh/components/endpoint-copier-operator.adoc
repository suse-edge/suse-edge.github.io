https://github.com/suse-edge/endpoint-copier-operator[端点复制器操作员] 是一个 Kubernetes 操作员，其目的是创建 Kubernetes 服务和端点的副本并保持它们同步。

== {product} 如何使用端点复制器操作员？

在 {product}，端点复制器操作员在实现 K3s/RKE2 集群的高可用性设置方面发挥着至关重要的作用。这是通过创建一个 `kubernetes-vip` 类型为 `LoadBalancer` 的服务来实现的，确保其端点与 Kubernetes 端点保持持续同步。利用 <<components-metallb,MetalLB>> 来管理 `kubernetes-vip` 服务，因为从其他节点加入集群时会使用暴露的 IP 地址。

== 最佳实践

有关使用端点复制器操作员的完整文档可以在 https://github.com/suse-edge/endpoint-copier-operator/blob/main/README.md[此处] 找到。

此外，请参阅 <<guides-metallb-k3s,我们的指南>>，了解如何使用端点复制器操作员和 MetalLB 实现 K3s/RKE2 高可用性设置。

== 已知问题
目前，端点复制器操作员仅限于处理一个服务/端点。未来计划进行增强以支持多个服务/端点。
