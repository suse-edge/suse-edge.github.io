== 概述

SUSE Telco Cloud（前身为 {product} for Telco）是一个针对电信优化的计算平台，使电信运营商和电信网络供应商能够进行创新并加速其网络现代化。

SUSE Telco Cloud 是一个完整的支持电信的云原生堆栈，用于托管 CNF，涵盖所有电信领域：分组内核、无线接入网 (RAN)、运营支撑系统 (OSS) 和业务支撑系统 (BSS)。

- 在电信级规模下，自动化实现复杂边缘堆栈配置的零接触部署与生命周期管理。
- 利用专为电信设计的配置和工作负载，持续确保电信级硬件的质量。
- 由专为边缘设计的组件组成，因此具备更小的占用空间和每瓦更高的性能。
- 保持灵活的平台策略，提供供应商中立的 API 和 100% 开源。
