SUSE Telco Cloud（原名 SUSE Edge for Telco）是一个面向电信行业优化的计算平台，使电信运营商和电信网络供应商能够创新并加速网络现代化。

SUSE Telco Cloud 是一个完整的支持电信的云原生堆栈，用于托管 CNF，涵盖所有电信领域：分组内核、无线接入网 (RAN)、运营支撑系统 (OSS) 和业务支撑系统 (BSS)。

- 实现电信规模下复杂边缘堆栈配置的零接触部署和生命周期管理的自动化。
- 使用电信特定的配置和工作负载，持续确保电信级硬件上的质量。
- 由专为边缘构建的组件组成，因此具有更小的占用空间和更高的每瓦性能。
- 保持灵活的平台策略，提供供应商中立的 API 和 100% 开源。
