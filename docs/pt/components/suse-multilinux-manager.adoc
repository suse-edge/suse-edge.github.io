= SUSE Multi-Linux Manager
:revdate: 2025-01-28
:revnumber: 3.7
:page-revdate: {revdate}
:experimental:


O SUSE Multi-Linux Manager está incluído no {product} para fornecer automação e controle para manter o SUSE Linux Micro como o sistema operacional subjacente consistentemente atualizado em todos os nós da sua implantação de borda.

Para mais informações consulte o <<quickstart-suma>> e o {link-mlm-documentation}[Documentação do SUSE Multi-Linux Manager].
