= SUSE Multi-Linux Manager
:revdate: 2025-01-28
:revnumber: 3.6
:page-revdate: {revdate}
:experimental:


SUSE Multi-Linux Managerは{product}に含まれており、エッジデプロイメントのすべてのノードで基盤となるオペレーティングシステムであるSUSE Linux Microを常に最新の状態に保つための自動化と制御を提供します。

詳細については、<<quickstart-suma>>および https://documentation.suse.com/suma/5.0/en/suse-manager/index.html[SUSE Multi-Linux Manager Documentation]を参照してください。
