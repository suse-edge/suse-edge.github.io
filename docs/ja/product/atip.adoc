== 概要

SUSE Telco Cloud（旧称：{product} for Telco）は、通信事業者や通信ネットワークベンダーがネットワークの革新と近代化を加速させることを可能にする、通信向けに最適化されたコンピューティングプラットフォームです。

SUSE Telco Cloudは、CNFをホストするための完全な通信対応クラウドネイティブスタックであり、すべての通信ドメインをカバーしています。パケットコア、RAN、OSS、およびBSS。

- 通信規模での複雑なエッジスタック設定のゼロタッチ展開とライフサイクル管理を自動化します。
- 通信固有の設定とワークロードを使用して、通信グレードのハードウェアにおける品質を継続的に保証します。
- エッジ向けに専用設計されたコンポーネントで構成されているため、設置面積が小さく、ワットあたりのパフォーマンスが向上しています。
- ベンダーニュートラルなAPIと100%オープンソースを備えた柔軟なプラットフォーム戦略を維持しています。
