SUSE Telco Cloud（以前はSUSE Edge for Telcoとして知られていた）は、通信事業者や通信ネットワークベンダーがネットワークの革新を促進し、近代化を加速させることを可能にする、通信向けに最適化されたコンピューティングプラットフォームです。

SUSE Telco Cloudは、CNFをホストするための完全な通信対応クラウドネイティブスタックであり、すべての通信ドメインをカバーしています。パケットコア、RAN、OSS、およびBSS。

- 通信事業者規模での複雑なエッジスタック構成のゼロタッチ展開とライフサイクル管理を自動化します。
- 通信事業者グレードのハードウェア上で、通信事業者固有の構成とワークロードを使用して、継続的に品質を保証します。
- エッジ向けに専用設計されたコンポーネントで構成されているため、フットプリントが小さく、ワットあたりのパフォーマンスが高くなっています。
- ベンダーニュートラルなAPIと100%オープンソースを備えた柔軟なプラットフォーム戦略を維持しています。
