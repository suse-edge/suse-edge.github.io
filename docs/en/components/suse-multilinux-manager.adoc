= SUSE Multi-Linux Manager
:revdate: 2025-01-28
:revnumber: 3.7
:page-revdate: {revdate}
:experimental:


SUSE Multi-Linux Manager is included in {product} to provide automation and control for keeping SUSE Linux Micro as the underlying operating system consistently up-to-date on all nodes of your edge deployment.

For more information please refer to the <<quickstart-suma>> and the {link-mlm-documentation}[SUSE Multi-Linux Manager Documentation].
